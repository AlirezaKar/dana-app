# پوشهٔ دادهٔ اکسل (storage/data)

فایل‌های اکسل مرجع (بدنه و شخص ثالث مالی) را در همین پوشه بگذارید.
نام هر فایل باید شامل یکی از این کلمه‌ها باشد تا دسته‌بندی شود:

* **بدنه** → `بدنه`، `badane`، `badene`، `body`
* **شخص ثالث مالی** → `ثالث`، `satheth`، `sath`، `third`

## ستون‌ها

فقط **نام سرستون‌ها** مهم است (ترتیب ستون‌ها، رنگ‌ها، RTL/LTR و ردیف عنوان بالای جدول اهمیتی ندارند).
ردیف سرستون به‌طور خودکار در ۱۰ ردیف اول پیدا می‌شود و مقادیر با **نام** سرستون تطبیق داده می‌شوند.

* ستون اجباری: **کد رایانه پرونده** (در فایل ثالث: `کد پرونده` / `کد رایانه پرونده`)
* تاریخ‌ها را به شکل جلالی `1405/07/01` بنویسید (اعداد فارسی هم قبول است)
* مبالغ می‌توانند با جداکنندهٔ هزارگان باشند
* ستون‌های اضافی و ناشناخته نادیده گرفته می‌شوند
* **ستون «رمز عبور» لازم نیست** — حساب‌های ورود در مدل کاربر ساخته می‌شوند
  (`manage.py create_user` / `seed_users`) و به این فایل‌ها ربطی ندارند

## به‌روزرسانی داده‌ها

هر بار فایل اکسل را ذخیره کنید، با نخستین باز شدن **صفحهٔ اطلاعات/آپلود** یا **صفحهٔ پایانی**
داده‌ها خودکار دوباره خوانده می‌شوند (به‌همین‌ترتیب نیازی به اجرای دستی
`python manage.py seed_sample_data` نیست). این کار با مقایسهٔ زمان تغییر فایل‌ها انجام می‌شود،
پس وقتی چیزی تغییر نکرده باشد هزینه‌ای ندارد. برای اجبار:

```bash
python manage.py seed_sample_data       # یا: python manage.py sync_data
```
